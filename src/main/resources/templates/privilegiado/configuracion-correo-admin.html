Conectar una cuenta

Google solicitará permiso para enviar correo. Solo esta cuenta de administrador puede autorizar el buzón.

La conexión de Google no está configurada en el servidor. Configura GOOGLE_CLIENT_ID y GOOGLE_CLIENT_SECRET para habilitarla.

Si cambias de proveedor, configura MAIL_PROVIDER en el servidor. Para Gmail API debe ser gmail-api; MAIL_FROM es opcional, pero si se configura debe ser la cuenta conectada o un alias autorizado en Gmail.
